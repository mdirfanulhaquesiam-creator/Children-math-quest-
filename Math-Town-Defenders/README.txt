MATH TOWN DEFENDERS

Run in VS Code:
1. Extract this ZIP file.
2. Open VS Code.
3. Choose File > Open Folder.
4. Select the extracted Math-Town-Defenders folder.
5. In the Explorer panel, double-click index.html.
6. Right-click index.html and choose Open with Live Server.
   Alternatively, click Go Live in the bottom status bar.

This is a self-contained HTML game. Its CSS and JavaScript are included
inside index.html, so no additional project files are required.

You can also open index.html directly in a web browser.
